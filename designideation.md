# DESIGN IDEATION DOCUMENT
## PRABHAV NARAYANAN | PERSONAL PORTFOLIO WEBSITE

**Project Name:** PRABHAV.exe  
**Project Type:** Personal Portfolio Website  
**Design Direction:** Retro CRT / Y2K / Vintage Digital Editorial  
**Primary Theme:** Connected to the past. Designed for the future.  
**Platform:** Responsive Web Application

---

# 1. Project Overview

PRABHAV.exe is a personal portfolio website designed to showcase my technical skills, software development projects, creative experiments, and musical identity through an unconventional digital experience.

Rather than following the traditional portfolio structure of a hero section, navigation bar, and project cards, the website will take inspiration from vintage television interfaces, early digital technology, Y2K graphic design, and underground editorial aesthetics.

The website will function as an interactive digital television, where visitors can explore different sections by switching between channels.

The objective is to create a portfolio that is not only informative but also visually memorable, interactive, and representative of my identity as a developer and creative individual.

# 2. Design Vision

The central design idea is to transform a personal portfolio into an interactive vintage television experience.

The interface will combine:

- Vintage CRT television aesthetics
- Y2K-inspired graphic design
- Pixel-based digital interfaces
- Electric blue and acid yellow color combinations
- Grainy textures and analog imperfections
- Black-and-white cutout photography
- Experimental typography
- Retro digital animations

The design should feel like an old television broadcasting a modern digital portfolio.

# 3. Visual Inspiration

The design direction is inspired by the provided visual references.

### Reference 01: Vintage Television Interface

Key visual elements:
- Curved television screen geometry
- Lime-yellow display background
- Pixelated typography
- Retro status indicators
- Minimal digital navigation
- Menu and Back interface elements

### Reference 02: Y2K Editorial Graphic Design

Key visual elements:
- Cobalt blue textured backgrounds
- Yellow star illustrations
- Black-and-white cutout portrait
- Bright yellow portrait outlines
- Grain and distressed textures
- Experimental typography
- Floating graphic elements

The two references will be combined into a unified visual language.

# 5. Typography

The typography system will combine retro pixel fonts with bold contemporary typography.

### Primary Display Typeface
Pixel-style fonts such as:
- Press Start 2P
- VT323

Usage:
- Television interface
- Channel numbers
- Status indicators
- Digital labels

### Secondary Typeface
Modern sans-serif fonts such as:
- Space Grotesk
- Inter
- Archivo Black

Usage:
- Headings
- Project descriptions
- About section
- Technical information

### Typography Principle

Pixel typography should be used selectively. The website must remain readable and avoid becoming a purely arcade-style interface.

**Foreground Layer**

- Slightly irregular rounded geometry
- Acid yellow display
- Black pixel typography

**Profile Layer**
- Black-and-white cutout portrait

- Decorative stickers and stars

**Navigation Layer**

The layout should feel like an experimental poster brought to life as a website.

# 8. Interaction Design

The website should provide an immersive but intuitive browsing experience.

### Television Interactions

- Switching channels changes the displayed content.
- Screen transitions include a brief CRT flicker.
- Menu opens the channel selector.
- Back returns to the previous channel.
- Hover states resemble physical television controls.

### Visual Effects

- CRT scanlines
- Screen curvature
- Analog noise
- Subtle RGB distortion
- Glitch transitions
- Flickering status indicators
- Animated stars and decorative elements

### Interaction Philosophy

Animations should enhance the experience without making the website difficult to navigate.

The interface must remain responsive, accessible, and usable on mobile devices.

# 9. Responsive Design

The website will adapt to desktop, tablet, and mobile screens.

### Desktop
- Large television interface
- Layered editorial composition
- Prominent portrait
- Full interactive channel navigation

### Tablet
- Reduced decorative elements
- Flexible TV dimensions
- Simplified channel controls

### Mobile
- Compact television screen
- Vertical layout
- Touch-friendly navigation
- Reduced visual effects
- Readable typography

The mobile experience should preserve the aesthetic identity rather than simply shrinking the desktop layout.

| Lucide Icons | Interface icons |

The design will prioritize lightweight animations and optimized assets.

# 11. Design Principles

### 01. Distinctive Identity
The website should be immediately recognizable through its visual style.

### 02. Controlled Nostalgia
Vintage elements should feel intentional and contemporary rather than outdated.

### 03. Interactive Storytelling
Visitors should discover different aspects of my identity through the channel-based experience.

### 04. Visual Hierarchy
Decorative elements must not compete with important portfolio content.

### 05. Usability
Navigation must remain understandable despite the experimental design.

### 06. Performance
Animations and textures should not significantly impact loading speed.

# 12. Expected Outcome

The final website should be a unique personal portfolio that:

- Differentiates itself from conventional developer portfolios.
- Communicates both technical and creative identity.
- Showcases software projects in an engaging manner.
- Demonstrates frontend development and interaction design capabilities.
- Creates a memorable experience for recruiters, developers, and visitors.

The intended result is an interactive digital portfolio that feels like a personal broadcast station from a parallel Y2K future.
